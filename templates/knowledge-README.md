# Project Knowledge

> Auto-generated project context. **WAJIB dibaca agent sebelum mulai kerja.**
> Ikuti metodologi yang terdaftar di bawah untuk workflow lengkap.

## Metodologi Aktif

| Skill | File | Fungsi |
|---|---|---|
| `$SKILL_USED` | `KNOWLEDGE.md` | Context, decisions, progress, learnings |
| `$SKILL_USED` | `DESIGN.md` | Design system spec (brand, tokens, typography, components) |

## Cara Pakai

1. **Baca ini dulu** — tau metodologi apa yang dipake
2. **Baca `KNOWLEDGE.md`** — lanjut dari state terakhir
3. **Kalau ada, baca `DESIGN.md`** — ikutin design system yang udah ditetapkan
4. **Update** file yang relevan setelah selesai kerja

## Aturan Agent

- `KNOWLEDGE.md` = append-only. Jangan hapus entry lama.
- `DESIGN.md` = referensi design. Update kalau ada perubahan keputusan visual.
- Setiap entry di `KNOWLEDGE.md` pakai timestamp `[YYYY-MM-DD]`.
- Agent WAJIB update file di `knowledge/` di setiap phase gate.
